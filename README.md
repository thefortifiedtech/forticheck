Forticheck is a Solana and BSC network token scanner that uses the GMGN API to find potential trading targets.  The bot searches for:

1. Community Take Over events on tokens
2. Smart money and KOLs buying into CTO tokens
3. Liquidity providing (Golden Phoenix) opportunities on CTO tokens with pools with high bin step
4. Velocity scalping opportunities on big price jumps
5. DLMM Alpha scanner finding Golden Phoenix opportunities on active Solana tokens
6. Imminent Breakout scanner for Top Solana tokens

The code is designed to run inside of a docker container on AWS.  The output signals are sent to a Discord channel.  The discord channel messages can be white labeled to allow multiple groups to use the same bot for signals.
